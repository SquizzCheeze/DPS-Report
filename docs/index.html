How it works

The game hides most combat numbers from addons while you play. Your combat log doesn't, so the app reads them from there and hands them to the addon.

Play as normal

Leave the app running in the tray. It follows WoW's combat log as it's written and never touches the game itself.

It copies when a fight ends

When a raid boss pull finishes (kill or wipe), or a Mythic+ key ends, that fight is exported to your clipboard with a Windows notification.

Paste it in game

In DPS Report, open the graph (the G on the meter, or /dpsgraph), click Import and press Ctrl+V. It's saved, so it survives a /reload.

What you get in game

An imported fight unlocks the parts of DPS Report that need the real per-second numbers.

Per-second graph

DPS, damage, HPS or healing for every player in the group, second by second, with 1s/3s/5s smoothing.

Ability breakdown

Each second split into the player's top abilities, with a coloured legend and the biggest three on hover.

Cast timeline

One lane per spell: every cast, and every DoT, HoT, buff or channel's uptime, zoomable and scrollable.

Compare fights

Lay another key or pull over the current one, on a shared timeline, with both totals and the difference.

Recent exports

Double-click the tray icon for the last 20 exports, any of which can be copied again later.

Light and open

No installer, no account, nothing sent anywhere. One small program, built from source anyone can read.

Install in a minute

There's no installer. It's a single file you can keep anywhere.

Getting started

  1. Install DPS Report from CurseForge if you haven't already.
  2. Turn on combat logging. In game, open DPS Report's options and on the Mythic+ page tick Log combat to file in dungeons and raids, or type /combatlog before you start.
  3. Download the app and put it somewhere permanent, such as your Documents folder.
  4. Double-click it. An icon appears by the clock. On Windows 11 it may be under the ^ arrow; drag it onto the taskbar to keep it in view.
  5. Right-click the icon and tick Start with Windows so it's always ready.
"Windows protected your PC"? Windows shows this for any program from a small developer without a paid signing certificate. Click More info, then Run anyway. You only need to do this once.

Requirements

  • Windows 10 or 11. Uses the .NET Framework that comes with Windows, so there's nothing else to install.
  • World of Warcraft (Retail) with the DPS Report addon.
  • Combat logging on for the fights you want to export.
  • Finds your game by itself. If WoW is somewhere unusual, right-click the icon, choose Change log folder and pick World of Warcraft\_retail_\Logs.

Questions

Is this allowed by Blizzard?

Yes. It only reads the combat log file that the game itself writes to disk, the same file Warcraft Logs and similar tools read. It doesn't connect to the game, read its memory or send any input to it.

Is it safe? Why would antivirus mention it?

The app is built automatically on GitHub from the source code in the DPS Report repository, where anyone can read it. Because it's new and unsigned, Windows SmartScreen and occasionally an antivirus can be cautious about it. It needs no administrator rights and sends nothing over the internet.

Nothing was copied after a fight. Why?

Check that combat logging was on for that fight, and that the tray icon's tooltip names a log file rather than "Waiting for a combat log". Only raid boss pulls and Mythic+ keys are copied automatically; you can always use Copy last key or Copy last boss pull from the tray menu.

I copied something else. Can I get an export back?

Yes. Double-click the tray icon to see the last 20 exports, pick one and click Copy selected.

Does it work while the game is running?

Yes, that's the point. Imports work without a /reload, and every imported fight is saved in the addon so it's still there after you log out.

How do I remove it?

Right-click the icon and untick Start with Windows, choose Exit, then delete the file. Its few settings live in %AppData%\DPSReportExporter, which you can delete too.

Is there a version for Mac?

Not at the moment; the app is Windows only.
